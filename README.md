# Trouve ton artisan

## Présentation

« Trouve ton artisan » est une plateforme permettant aux particuliers
de rechercher un artisan situé en Auvergne-Rhône-Alpes.

Les utilisateurs pourront :

- consulter les artisans par catégorie ;
- rechercher un artisan par son nom ;
- consulter la fiche détaillée d’un artisan ;
- envoyer une demande à un artisan depuis un formulaire de contact.

## Contexte

Ce projet est réalisé dans le cadre de la formation Développeur Web.

Le site doit respecter les besoins définis dans le brief fourni,
notamment le responsive design, l’accessibilité, la sécurité
et l’utilisation d’une API REST connectée à une base de données MySQL.
